# Support policy

Tinkerbot 0.1.x supports Node.js 20+, Git 2.x, TypeScript/JavaScript/Python/Go/Rust/C/C++ repositories, repository-controlled test commands, LCOV/Istanbul/coverage.py/Go/gcov/LLVM artifacts, and GitHub Actions using safe `pull_request` events. The product UI is the hosted dashboard; local `tb check` does not require a hosted session.

For a reproducible support request, include the Tinkerbot version, Node version, platform, command, sanitized `tb config explain` output, report verdict, and limitation text. Do not include source code, secrets, or unredacted diffs.

The project has no hosted support desk or SLA in this pilot release. Before publishing, the release owner must replace the repository placeholder with the project’s issue and security-reporting URLs.
