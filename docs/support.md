# Support policy

Tinkerbot 0.1.x supports Node.js 20+, Git 2.x, Bun/OpenTUI for the local cockpit, TypeScript/JavaScript/Python/Go/Rust/C/C++ repositories, repository-controlled test commands, LCOV/Istanbul/coverage.py/Go/gcov/LLVM artifacts, and GitHub Actions using safe `pull_request` events.

For a reproducible support request, include the PR Proof version, Node version, platform, command, sanitized `pr-proof config explain` output, report verdict, and limitation text. Do not include source code, secrets, or unredacted diffs.

The project has no hosted support desk or SLA in this pilot release. Local verification and the TUI do not require hosted access. Before publishing, the release owner must replace the repository placeholder with the project’s issue and security-reporting URLs.
